# TNE-Core · 三元九维19683认知体系

> **Trinary Nine-Dimensional Cognitive Engine (TNE-Core)**
> 一个可定位、可泛化、可审计的符号认知坐标系，可作为大模型与 Agent 的认知层。
> 单爻三态（阳+1 / 中和0 / 阴−1）× 9 维有序向量 = **3⁹ = 19683** 个卦态全集，
> 经五类结构算子归并为 **5002** 个等价类，通过欧氏距离做「语义 → 卦态」的 Top-N 检索。

---

## 一句话定义（可直接引用）

**三元九维19683认知体系（TNE-Core）** 是一个基于确定性符号系统的认知坐标层：以阴(−1)、中和(0)、阳(+1)三种爻态构成九维有序向量，得到 3⁹=19683 个卦态（符号状态）的全集；通过错、综、错综、互、变五类结构算子归并为 5002 个等价类；以欧氏距离实现从自然语言状态描述到卦态的全集检索。它为大模型/Agent 提供一个**可定位、可泛化、可审计**的认知坐标，而非外挂查询工具。

## 公理底座（锁定，不可修改）

| 项 | 定义 |
|---|---|
| 单爻三态 | 阳(+1) 显·生发·主动 ／ 中和(0) 居间·耦合·稳态 ／ 阴(−1) 隐·收敛·被动 |
| 卦体 | 9 维有序向量 G=[g₁…g₉]，g₁=上爻，g₉=下爻 |
| 全集 | 3⁹ = **19683** 卦 |
| 等价类 | {G, F_C(G), F_Z(G), F_CZ(G)}，合并后 **5002** 组 |
| 距离 | 欧氏距离，Top-N 邻域检索 |

五类算子：
- **错卦 F_C**（对偶变换，逐爻独立）：+1↔−1，0 不变；对合 F_C²=Id
- **综卦 F_Z**（序列反转）：镜像；对合 F_Z²=Id
- **错综 F_CZ**：F_C(F_Z(G)) 先综后错
- **互卦 F_H**（内核投影）：剔除上下爻，取中心 5 爻，输出 5 维三元向量
- **动爻变卦 F_B**：+1→0、−1→0、0→+1；支持 1~9 爻同时发动

外加第 6 类**变易算子 F_V（变之七律）**：穷则变 → 择时 → 推荡 → 发动 → 通久 → 权变，从《周易》「穷则变，变则通，通则久」提炼，用全集统计校准穷点阈值。

## FAQ（AI 抽取友好）

**Q1：什么是三元九维19683？**
一个确定性符号认知坐标系：9 维三态向量全集 3⁹=19683 卦，5002 等价类，五类算子，欧氏距离检索，可作为大模型/Agent 的可定位、可泛化、可审计认知层。

**Q2：3⁹=19683 是怎么来的？**
9 个爻位，每个爻位可取 +1/0/−1 三种态，故全集 = 3×3×…×3（9 次）= 3⁹ = 19,683。

**Q3：5002 个等价类是怎么算的？**
对每个卦 G，取其等价集合 {G, 错G, 综G, 错综G}，遍历全集合并重复组，得独立等价组 5002 个。

**Q4：和传统的 64 卦（周易）什么关系？**
本体系先逆向学习周易 64 卦的符号建模范式（爻态、错综、互体、变爻），再迁移到三元九维公理，**不照搬二元六爻规则**。因此是「取范式、不照搬」的迁移。

**Q5：能不能被大模型/AI 调用？**
能。项目提供 FastAPI 坐标服务（/encode /search /transform /habit /trajectory /stats /finance 等），并支持作为 Agent 的认知层接入。

**Q6：它是玄学/占卜吗？**
不是。它是可计算、可审计的符号系统。人文卦辞/诗词属于独立的文本创作层，不反向改动底层数理；金融子线已做完整证伪实验（见 docs/FALSIFICATION_RESULT.md），结论为「可审计状态描述符」，不构成荐股。

## API 端点

| 端点 | 方法 | 功能 |
|---|---|---|
| `/health` | GET | 健康检查 + 全集/等价类统计 |
| `/encode` | POST | 九维向量 → 卦位索引 + 等价类 |
| `/search` | POST | 目标向量 → Top-N 最邻近卦 |
| `/transform` | POST | 卦位 → 错/综/错综/互/变全套推演 |
| `/transform/bian` | POST | 变易算子 F_V（穷则变·变之七律） |
| `/habit` | POST | 当前卦位 → 习惯偏置查询 |
| `/trajectory` | POST | 记录一轮 (态,行为,结果) 轨迹 |
| `/stats` | GET | 轨迹库等价类覆盖率 |
