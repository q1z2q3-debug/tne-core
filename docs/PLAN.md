# TNE-Core 执行计划

> 从论文的相空间地基，到运行时内化的认知引擎。三阶段，逐步验证，不跳步。

## 阶段一：外挂认知层产品化（当前 · 2-4 周 · 无 GPU）

**目标**：把坐标服务做成 LLM/Agent 可调用的工具，跑通"定位→轨迹→习惯"闭环。

### 已完成
- [x] 相空间内核：19683 态枚举 + 三态编解码
- [x] 五类算子：错/综/错综/互/变，论文样例全部通过
- [x] 等价类：5002 组，遍历全集验证
- [x] 距离检索：欧氏距离 + Top-N 邻域
- [x] 轨迹库：SQLite，(态,行为,结果,时间戳) 自动落盘
- [x] 习惯偏置：命中→习惯模式 / 未命中→探索模式
- [x] FastAPI 坐标服务：7 个端点
- [x] 单元测试：7 项全部通过

### 待完成
- [ ] **接入真实 Agent**：选一个垂直场景（投资分析 / 诗词创作 / 中医辨证），让 Agent 每轮调用 `/encode` 定位、`/trajectory` 落盘、`/habit` 取偏置
- [ ] **跑 1000 轮真实任务**：填满轨迹库，等价类覆盖率 > 30%
- [ ] **行为分布分析**：同一等价类下行为是否收敛（熵 < 1.0 算收敛）
- [ ] **LLM function calling 集成**：把 API 封装成 OpenAI function schema，大模型可自动调用
- [ ] **Docker 化**：FastAPI + SQLite 一键部署

### 验证标准
- Agent 决策可审计率 > 80%（每步能说出"我在哪个卦位"）
- 高频等价类（命中≥5次）行为复用率 > 60%
- API 响应 < 200ms

## 阶段二：运行时投影实验（2-4 周 · 1× GPU）

**目标**：验证根本假设——九维三态是否是 LLM hidden state 的自然坐标。

### 任务
1. **标注数据**：人工标注 1000-2000 条 (情境文本, 九维标签)
2. **hidden state 抽取**：选 7B 基座模型，用 vLLM 推理，取指定层指定 token 的 hidden state
3. **层/Token 消融实验**：测试不同层（最后一层/中间层/第 20 层）、不同 token（输入末 token/reasoning 聚合）的投影效果
4. **最小 Projector 训练**：MLP 4096→256→27 logits→硬三态，交叉熵损失
5. **准确率评测**：对标人工标注

### 关键决策点
| Projector 准确率 | 决策 |
|---|---|
| > 75% | 继续阶段三 |
| 60-75% | 调整坐标设计（增加维度 / 改变三态定义） |
| < 60% | 放弃 hidden state 路线，回到"吃文本的外挂认知层" |

### 验证标准
- 投影准确率 > 75%
- 找到最优 hidden state 抽取点（层 + token）
- 九维态分布均匀（无某态占比 > 50%）

## 阶段三：TNE-Core 全量（3-6 月 · 4× A100 80G）

**目标**：完整认知闭环——投影→轨迹→习惯→张力→动力→内化。

### 模块 4：认知动力引擎（Drive）
- 张力检测：novelty（态出现频率低）/ boundary（Projector 置信度低或邻域卦辞冲突）/ habit_conflict（当前行为与历史习惯不一致）
- 动力信号：curiosity / deliberation / meta_reasoning
- 注入器：注入 system_prompt 或 reasoning_prefix

### 模块 5：动态等价学习器（Dynamics）
- merge_finder：行为分布相似的类 → 合并（行为层等价，不修改符号层 5002 类）
- split_finder：类内行为方差大 → 拆分
- topology：输出动态等价类映射表（叠加层）

### 模块 6：内化蒸馏管线（Distill）
- data_gen：用外挂 Projector 生成 SFT 训练数据 (hidden, 9d)
- sft：微调让模型并行输出九维态 + 审计
- reward：RL 奖励 = 0.3×习惯匹配 + 0.2×探索成功 + 0.4×边界消解 - 0.3×习惯冲突未检测
- merge：LoRA 合并回基座

### 涌现能力评测矩阵
| 能力 | 评测方式 | 达标线 |
|---|---|---|
| 认知连续性 | 关掉 Agent 24h 后重启，查等价类偏置是否保留 | 偏置一致率 > 95% |
| 习惯自动化 | 高频类命中时，Agent 是否直接复用行为（不显式查历史） | 复用率 > 80% |
| 主动停机 | 注入"继续做会恶化"的态，Agent 是否主动停止 | 停机率 > 70% |
| 认知好奇心 | novelty 张力下，Agent 是否主动追问/探索 | 追问率 > 70% |
| 元认知自觉 | habit_conflict 下，Agent 是否说出"我的习惯可能不适用" | 自觉率 > 60% |
| 风格固化 | 100 轮后，同一等价类下行为分布是否收敛 | 分布熵 < 0.5 |
| 跨域迁移 | 领域 A 形成的习惯能否泛化到领域 B 同类态 | 迁移成功率 > 65% |

**双盲评测**：关掉 Drive 注入和轨迹查询，只看模型自身行为是否保留习惯偏置。关掉后行为回归随机 = 未真正内化。

## 风险与兜底

| 风险 | 兜底 |
|---|---|
| Projector 投影准确率低 | 先用论文的 encode（吃文本）兜底，Projector 并行跑逐步切换 |
| 轨迹积累太慢 | 用合成任务批量跑，只要覆盖等价类 |
| 内化蒸馏效果差 | 保留外挂 Projector 作为 fallback，不做"全内化"硬切换 |
| 涌现能力评测不达标 | 退一步：当"可审计的认知坐标工具"用，已达论文水平 |
| 团队资源不足 | 砍到最小：只做模块 1+2+3，验证"映射→轨迹"闭环，两周可出 |

## 一句话

TNE-Core 的终极落地 = 论文的相空间（地基）+ 运行时投影（内化）+ 轨迹审计（自觉）+ 动态等价（习惯）+ 张力动力（主体）+ 蒸馏内化（基因）。六个模块，12 周，4 张 A100，最小团队 5 人。
