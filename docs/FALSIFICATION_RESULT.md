## 2. 两个关键方法学发现

### 发现1：绝对阈值态在横截面内无区分度（A股系统性同涨同跌）
用 finance_mapper 的**绝对阈值**（月≥2%阳等）对同一截面内 30 只股票判定，几乎全部落在同一态——A股高贝塔、系统性同涨同跌，个股绝对涨跌横截面高度同质。
→ **绝对态是"时间序列标签"（单股跟踪诊断），不是"横截面因子"（横向选股）**。这是对生产画像的实证澄清，不是缺陷。

### 发现2：相对强弱态捕获动量信号（有效）
改为**个股涨跌相对截面中位数的强弱**（相对差>1pp 判阳/阴）后，截面内获得区分度，且出现真实信号：
- 两周动量 g5 最强（IR=0.81）
- 三趋势分综合 IC=0.108、IR=0.66
- 随机基线 99% 分位 → 不是任何三态标签都有的伪信号

> 注：该动量效应与金融学已知的"短期动量/趋势延续"一致，九维三态化**保留并量化**了这一信息——证明三态离散化不是破坏性的。

## 4. 局限（如实）

1. **检验A不显著**：分层价差 p=0.29。原因：面板内同一股票跨截面相关，简单 Welch t 检验违反独立性假设、检验力不足；IR 有效但均值差检验未过。
2. **时间窗短**：仅 2.6 年、16 个截面，横截面观测少。
3. **股票池偏大中盘**：未覆盖中小盘，动量在小盘可能更强/更弱。
4. **未控制因子**：未做行业中性、未控制市值/估值等混淆。
5. **行情维度子集**：未含财务(g3/g4/g8)/估值(g7)/换手(g6)维度——完整九维待第二批接入。

## 6. 结论陈述

九维行情态（相对强弱版）对未来收益存在**可检测的正向关联**，方向与金融学动量效应一致，随机基线证实非偶然；但当前证据强度为"IR 有效 + 随机通过 + 均值差未达严格显著"，判定**部分通过**。绝对阈值版在横截面场景无区分度，应定位为单股时序诊断标签。
