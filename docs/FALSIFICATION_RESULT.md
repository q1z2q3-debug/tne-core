# 证伪实验结果 · 九维行情态对未来表现的统计关联

> 实验版本：v1 · 行情维度子集（g1月/g2当日/g5两周/g9年趋势）+ 检验D双重固定效应
> 执行日期：2026-10-19 · 脚本：`scripts/experiment_runner.py`

## 1. 结论速览

| 检验 | 结果 | 判定 |
|---|---|---|
| 检验A · 主态分层价差 | 强势>弱势（方向对），ret60 价差 +1.77pp，p=0.29 | 未达 p<0.05 |
| 检验B/C · 截面 RankIC | g5(两周) IC=+0.137 **IR=0.81**；三趋势分 IC=+0.108 IR=0.66；随机基线 99.0% 分位 | 横截面有信号 |
| **检验D · 双重固定效应面板回归** | **tscore3 系数 −0.0136，t=−4.04，p=0.0001** | **显著（方向反转）** |
| **检验D' · FE 系数随机基线** | 200 次打乱，真实系数位于随机分布 **0.0% 分位** | **显著非偶然** |

**综合判定：因果方向澄清——九维趋势态是"横截面动量 + 个股内时点反转"的双面体。**
同一个态，横截面与时序两个方向符号相反；这是比"动量有效"更严谨、更反直觉、也更有价值的发现。

## 2. 核心发现（本轮最重要）

### 发现1：截面 RankIC 为正 → 强股恒强（横截面异质性）
检验B/C 测到正 IC：**强的股票未来也强**。但这主要来自**个股固定特征**（长期强股 vs 长期弱股），不是时点择时信号。

### 发现2：剔除个股固定效应后 → 时点反转（显著为负）
检验D 用股票+日期双重固定效应吸收个股异质性和市场整体涨跌后，tscore3 对 ret60 的系数 **−0.0136（p=0.0001，聚类稳健SE）**，且随机基线证实非偶然：
**在个股内部，相对自身偏强的时点之后 60 日倾向走弱（短期反转）。**

### 发现3：检验A不显著的原因被解释
检验A的简单均值差把"横截面正效应"和"个股内时点负效应"**混合抵消**了，故 p 不显著。这不是无信号，而是两个方向的信号叠加。

### 发现4：绝对阈值态横截面无区分（A股系统性同涨同跌）
finance_mapper 的绝对阈值在单截面内几乎全部同态 → **绝对态=时序诊断标签，不是横截面因子**。

## 3. 对九维画像用途的澄清

| 用途 | 九维态的角色 | 实证结论 |
|---|---|---|
| 单股时序诊断 | 绝对态 · 跟踪强弱轨迹 | 有效（描述符），不构成择时 |

| 个股内择时 | 相对态 · 时点信号 | **反转（FE 显著负）**——不可直接追强 |

## 5. 局限（如实）

1. **时间窗短**：2.6 年、16 截面，样本有限。
2. **无完整九维**：未含财务/估值/换手维度——完整画像待验证。
3. **未行业中性**：FE 按股票吸收个体效应，但未单独隔离行业轮动。
4. **ret60 重叠窗口**：相邻截面未来收益重叠，虽然用聚类稳健 SE 缓解，仍有相关性。

## 7. 结论陈述

九维行情态不是单一方向的预测器：**横截面是动量（强股恒强），个股内时序是反转（偏强后回落）**。检验D的双重固定效应回归（p=0.0001）与随机基线（0% 分位）证实了这一点。**九维画像作为状态描述符完全成立；作为预测信号必须区分"选股"与"择时"两个用途，二者方向相反。**

*研究辅助，非投资建议，不构成荐股。关联≠因果。*
