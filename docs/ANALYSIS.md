## 关键发现

### 1. 习惯偏置机制生效 ✅
习惯复用率 61.0%，超过 60% 达标线。高频等价类在积累 ≥3 条历史后，Agent 以 80% 概率复用历史最优行为。这验证了"轨迹→习惯→行为复用"闭环。

### 2. 行为收敛需要更多轮次 ⚠️
平均行为熵 1.449，无类收敛到熵<0.5。原因：
- 模拟 Agent 保留 20% 随机探索率（设计如此，避免过早收敛）
- 每类平均 111 轮，分布在 4-8 个行为上，还不足以压平分布
- 真实 LLM Agent 的行为空间更集中，收敛会更快

**预期**：将探索率降至 10%、跑 5000 轮后，高频类应收敛到熵<1.0。

### 3. 覆盖率受限于情境多样性 ⚠️
12 个预设情境只覆盖 12 卦位 / 9 等价类。这是模拟 Agent 的固有局限。真实 Agent 接入后，情境多样性会大幅提升覆盖率。

**阶段一目标**：等价类覆盖率 >30%（1500+ 类）需要真实 Agent 或 500+ 多样化情境。

### 4. 习惯模式成功率显著高于探索 ✅
习惯模式下成功率约 75%，探索模式约 50%。这验证了"习惯复用 = 经验复用"的假设。

## 结论

阶段一核心闭环（定位→轨迹→习惯→复用）**已验证可行**：
- ✅ 坐标服务 API 稳定（1000 轮零错误）
- ✅ 轨迹库自动落盘正常
- ✅ 习惯偏置查询生效，复用率达标
- ✅ 习惯行为成功率高于探索行为

待优化：
- ⚠️ 行为收敛需要更多轮次或更低探索率
- ⚠️ 等价类覆盖率需要真实 Agent 或更多情境
- ⚠️ 需接入真实 LLM 验证"认知可审计性"
