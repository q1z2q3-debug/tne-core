# CogOS · 认知空间 OS 骨架（最小可运行版）

> 结构隐于内，语言形于外：对话、记忆、分析、判断都在九维认知空间里完成，
> 对外只输出人类语言，不显露卦位、坐标与算子。

## 1. 定位

CogOS 不是一个新的符号系统，而是把已有的 TNE 相空间（19683 态 / 5002 等价类 / 五算子）
装成一套**可运行的认知底坐**：

- 输入：自然语言
- 内部：映射到九维三态 → 空间记忆检索 → 三层分析 → 结构共振
- 输出：正常的人类语言

公理层完全不动。CogOS 只做"用"的部分。

## 2. 四层调制（分时介入，不是同时叠加）

| 层 | 介入时点 | 作用 |
|---|---|---|
| ① 领域帧 | 映射前 | 选基准语义轴与长期偏移 |
| ② 上下文调制 | 映射前（一次性） | 按本轮主题调临时权重 |
| ③ 共振反馈 | **映射后**（迭代收敛） | 用初步卦位找记忆共振 → 调轴 → 重映射 |
| ④ 演化累积 | **跨轮** | 把轴位移写回 bias，下一轮生效 |

关键约束：③ 只接受**强结构关系**（对偶/倒映/内核）的记忆参与调轴；
仅有空间邻近（near）的记忆不参与，避免无关内容污染当前语义轴。

## 3. 五段闭环

```
映射 → 记忆调动 → 三层分析 → 共振创造 → 人类语言
```

1. **映射**：四层调制把文本压成卦位，附置信度。
2. **记忆调动**：先空间（等价类 + 欧氏邻域），有候选才进内容层（关键词相关度）。
   - 空间无候选 → `miss`，直接新建
   - 空间有候选 + 内容相关 → `hit`，沿用旧结论
   - 空间有候选 + 内容不相关 → `association`，转联想，不覆盖原记忆
3. **三层分析**：卦层（姿态/净极性/穷度）、爻层（九维逐项）、索引层（错/综/互/变 + 邻域）。
4. **共振创造**：异质同构——结构同类、内容无关的经验被牵引出来。
5. **人类语言**：只出判断与建议，结构术语零外泄（有单元测试守护）。

写回规则：`conf ≥ 0.35` 且非全中和才算"方向成立"，才允许写入记忆。

```

```

## 5. 运行

```bash
cd tne-core
PYTHONPATH=src python3 scripts/cogos_demo.py     # 五轮链路
PYTHONPATH=src python3 scripts/test_cogos.py     # 27 项断言
```

演示实测（同一会话内 5 轮）：

| 轮 | 输入主题 | 卦位 | 置信 | 记忆状态 |
|---|---|---|---|---|
| 1 | 流程重做但方法与资料不足 | `+00000000` | 0.178 | miss（方向未立，不记） |
| 2 | 目标明确 + 三步方法 + 资料齐 | `+11 1 00+00` | 0.656 | miss → 新建 |
| 3 | 团队沟通累、对立、犹豫 | `0-000-000` | 0.363 | association（转联想） |
| 4 | 决定拖延、方向不明、经验不足 | `-000000-0` | 0.332 | association（不记） |
| 5 | 同主题推进（方法/资料/目标） | `+0+1 00+00` | 0.556 | **hit**（沿用旧结论） |

## 6. 五个设计决策

1. **映射吃文本，不吃 hidden states**：本版是可跑骨架，先用词典保证链路闭环；
   模型投影属于 `projector/` 的后续接入，接口 `raw_scores(text) -> 9 维` 保持不变即可替换。
2. **输出硬三态，不做连续回归**：三态本身就是认知判断（收敛/驻留/生发），连续值会模糊语义。
3. **空间先于内容**：没有位置就没有该处的内容，避免"关键词碰巧相同"被当成记忆命中。
4. **共振反馈只认强结构**：邻近不算共振，否则无关内容会把语义轴拉歪（已由单测锁定）。
5. **方向未立不记忆**：低置信或全中和的输入只走分析，不污染长期记忆。

## 7. 已验证 / 局限

已验证（`scripts/test_cogos.py` 全过）：

- 19683 全集、5002 等价类、五算子样例与本项目公理单元测试完全一致
- 映射确定性、置信度区间、等价类索引一致
- 空库必 miss、近内容 hit、结构近而内容远转 association
- 低置信不写入
- 邻近不调轴、对偶调轴
- 三轮回复无任何结构术语泄漏

明确局限：

- 词典覆盖有限，中文口语的否定/反讽/长句仍会误判；这是可替换的**特征源**，不是公理。
- 演化累积已实现但样本太少，bias 目前全为 0（需真实多轮才看得出漂移）。
- 尚未接 projector（hidden states → 九维）与 FastAPI 端点。
- 共振生成是模板化句式，不是自由写作。
